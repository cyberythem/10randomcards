# 10 Random Cards

A collection of 10 fun, interactive, and multi-functional tools built into a single, sleek, glassmorphic dashboard. Whether you need an excuse for a bad game, a quick anime quote, or just want to pass the time, this dashboard has you covered.

## 🚀 Live Here
10randomcards.vercel.app

## ✨ Features
This dashboard features 10 distinct interactive cards:

1. **Anime Quote Generator**: Get inspired with randomized lines from your favorite series.
2. **Card Painter**: Dynamically change the card's background color with a click.
3. **Text Reverser**: Flip your text instantly.
4. **Coin Flipper**: Simple heads or tails decision-maker.
5. **Content Generator**: Get funny, sarcastic, and relatable ideas for your next social media post.
6. **Magic 8-Ball**: Get the answers you didn't know you needed.
7. **Secure Password Generator**: Generate strong, random 12-character passwords.
8. **Match Loss Excuse**: Need a reason for that last defeat? Get a hilarious, real-world gaming excuse.
9. **D20 Dice Roller**: A classic 20-sided dice roller for gaming.
10. **Word Counter**: Quickly count the words in any text input.

## 🛠 Tech Stack
* **HTML5**: Structured dashboard layout.
* **CSS3**: Implemented with **Liquid Glassmorphism** and dynamic gradient animations for a modern, funky aesthetic.
* **Vanilla JavaScript**: Logic for randomness, state management, and interaction.

## 📦 Project Structure
* `index.html`: Main dashboard structure and layout.
* `style.css`: Visual styling, animations, and responsive design.
* `script.js`: Logic for randomization, non-repeating deck system, and card interactions.

## 🚀 How to Run Locally
1. Clone this repository to your local machine.
2. Open `index.html` in your favorite web browser.
3. Enjoy your 10 Random Cards!
